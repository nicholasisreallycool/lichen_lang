lichen

A tiny programming language that grows on you.

Python's feel with a few C++ touches. A lexer, a parser, and an interpreter, built from scratch in about 1,500 lines of Python.

View on GitHubInstall it
// Greeting and a little math
const name = "lichen"
print("Hello from " + name + "!")

fn fib(n) {
  if n < 2 {
    return n
  }
  return fib(n - 1) + fib(n - 2)
}

for i in range(8) {
  print("fib(" + str(i) + ") =", fib(i))
}

What it's like

Familiar syntax
Braces, no semicolons, and and, or, not. If you know Python or C++, you can already read it.
A const that means it
Values declared with const can't be reassigned, and the interpreter enforces it.
Functions you can pass around
Return one function from another and it remembers its variables.
Errors that point
Syntax and runtime errors tell you the line, and for syntax errors the column.
A REPL
Run lichen with no file and try things out live.
Small enough to remix
The lexer, parser, and evaluator live in separate short files. Fork it and grow your own language.

Install

You need Python 3.9 or newer.

git clone https://github.com/nicholasisreallycool/lichen_lang.git
cd lichen_lang
pip install -e .
lichen examples/demo.lch

Run lichen on its own to open the REPL.

if x > 3 and x != 7 {
  print("big")
} elif x == 3 {
  print("three")
} else {
  print("small")
}

while x > 0 {
  x--
}

Functions and closures

fn adder(n) {
  fn add(m) {
    return n + m
  }
  return add
}

print(adder(5)(3))   // 8
